# Bundled math reference set for benchleak.

# Every line below is an original grade-school math word problem written for
# this project and never published elsewhere, so no released model can have
# trained on these exact strings. They mirror the GSM8K format (question,
# step-by-step solution with <<...>> calculator annotations, "#### N" final
# answer) so that when a math benchmark is scanned, the benchmark and reference
# differ only in whether the model has seen them — not in domain or format.
# The arithmetic in every <<expression=value>> annotation is machine-verified
# by the test suite. Blank lines and lines beginning with '#' are ignored.
#
# Used automatically for benchmarks registered with the "math" domain
# (gsm8k, math); override with --reference.
